# ExpenseX AI — Intelligent Personal Finance Landing Page

State-of-the-art interactive web application and landing page for **ExpenseX AI**, built with React, TypeScript, Three.js, and Framer Motion.

## Features
- **3D Interactive iPhone 17 Pro Max**: CAD-accurate 3D phone model built with Three.js featuring real-time orbital lighting, floating 3D metallic currency coins, AI neural core chip, bar chart metrics, and interactive 360° mouse drag rotation.
- **Interactive Quick Tour (5 Steps)**: Step-by-step walkthrough of Voice Capture, Transaction Categorization, Financial Intelligence, Predictive Alerts, and Autonomous Budgets with locked stationary controls and smooth vertical text carousels.
- **Multi-Channel Capture**: AI Vision OCR Receipt Scanning, Bank Alert SMS Parser, Digital Invoice Email Detection, and WhatsApp AI Assistant.
- **Luxury App Download Banner**: Full-width conversion card with authentic Apple App Store and Google Play Store badges, 3D app icon tile, and celebration effects.
- **Audio Micro-Interactions**: Custom Web Audio synthesizer sound effects and interactive haptics.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics**: Three.js
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Confetti**: Canvas-Confetti

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
